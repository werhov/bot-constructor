🚀 БЫСТРЫЙ СТАРТ:

1️⃣ Распакуйте архив
2️⃣ Установите зависимости:
   npm install

3️⃣ Создайте бота в @BotFather и получите токен

4️⃣ Настройте .env файл:
   cp .env.example .env
   # Отредактируйте и добавьте ваш токен

5️⃣ Запустите:
   npm start              # Сервер
   node main-bot.js       # Бот

6️⃣ Откройте бота в Telegram и нажмите /start 🎉

🐛 TROUBLESHOOTING:

Проблема: Бот не отвечает
→ Проверьте токен в .env файле
→ Убедитесь что server.js запущен
→ Проверьте логи: node main-bot.js

Проблема: Mini App не открывается
→ Убедитесь что HTTPS настроен
→ Проверьте URL в @BotFather → Menu Button
→ Проверьте порт в .env (по умолчанию 3000)

Проблема: Ошибки при установке
→ Проверьте версию Node.js: node -v (нужна >= 16)
→ Очистите кэш: rm -rf node_modules && npm install
